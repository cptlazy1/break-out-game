# Breakout Game

## Specifications

The gameplay of "Atari Breakout" is straightforward but challenging. Players must prevent the ball from falling off the screen while aiming to destroy all the bricks.

### Features
* **Progressive Difficulty:** As players advance, the speed of the ball increases, requiring quicker reflexes and strategic planning.
* **Scoring System:** Points are awarded for each brick destroyed, encouraging players to aim for high scores.

## Plan
1. **Game Setup:** Initialize the game window using the `turtle` library.
2. **Core Objects:** Create the Paddle, Ball, and Bricks.
3. **Movement:** Implement controls for the paddle and physics for the ball.
4. **Collisions:** Handle ball bouncing off the paddle, walls, and breaking bricks.
5. **Game Logic:** Implement the scoring system, progressive difficulty, and win/loss conditions.
